# FDA-source Nexplanon in-vitro release data

This directory contains two digitized release-rate datasets transcribed from the supplied `organon data.xlsx` workbook. They are published, source data from the FDA's 2006 *Clinical Pharmacology and Biopharmaceutics Review* for NDA 021529 (Nexplanon/etonogestrel implant), rather than data generated by this model.

## `fda_nexplanon_real_time_release.csv`

| Item | Description |
|---|---|
| Release medium | Purified water, 100 mL |
| Temperature | 37 °C (FDA review) |
| Agitation | 750 rpm (supplied workbook) |
| Sampling | Release amount measured daily; medium replaced daily |
| Time range in this file | 1 to 1,261.66 days (~3.5 years) |
| Reported fields | Time, mean release rate, available standard deviation, and relative standard deviation |

The FDA review describes real-time testing in water at 37 °C, with daily determination of etonogestrel released and daily medium refreshment. It describes the test as being used for development and stability and as comparable with in-vivo daily release. The supplied workbook records the 100 mL volume, 750 rpm agitation, and an approximately 5% sink-condition estimate.

## `fda_nexplanon_accelerated_release.csv`

| Item | Description |
|---|---|
| Release medium | 100 mL, 90:10 ethanol:water (v/v) |
| Temperature | 45 ± 0.2 °C |
| Agitation | 750 rpm (supplied workbook) |
| Sampling | Every 24 hours; medium replaced after sampling |
| Assay | UV spectrophotometer with a flow-through cell (FDA review) |
| Time range in this file | 1.11 to 20.00 days |
| Reported fields | Time, release rate in mg/day, and the identical value converted to mcg/day |

The FDA review states that the accelerated method is intended to mimic three years of release in approximately 18 days; six accelerated-release days correspond to one year of the real-time test. The 20-day range retained here is the complete range supplied in the workbook.

## Source and use notes

- FDA, Center for Drug Evaluation and Research. *Clinical Pharmacology and Biopharmaceutics Review*, NDA 021529, 2006: [PDF](https://www.accessdata.fda.gov/drugsatfda_docs/nda/2006/021529s000_ClinPharmR.pdf).
- FDA, Center for Drug Evaluation and Research. *Clinical Review*, supplemental NDA 021529/SES-007, 2011, section 7.2.3: [PDF](https://www.accessdata.fda.gov/drugsatfda_docs/nda/2011/021529Orig1s007.pdf).
- The CSVs preserve the supplied numerical values; blank SD/RSD cells mean those values were not supplied, not zero variability.
- These data are for research and reproducibility. They do not establish product specifications or replace a validated release method.
